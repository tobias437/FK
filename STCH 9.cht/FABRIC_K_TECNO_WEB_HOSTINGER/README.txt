FABRIC K TECNO — versión para Hostinger

Archivo principal: index.html

Esta versión conserva el HTML/CSS/JavaScript generado por Stitch.
Las imágenes del catálogo que la página utiliza están referenciadas desde sus URLs
originales, por lo que no se degradan ni se recomprimen dentro del ZIP.

Subida:
1. Extraer el ZIP.
2. Subir el contenido de esta carpeta al directorio público de Hostinger (normalmente public_html).
3. El archivo index.html debe quedar directamente dentro de public_html.

No subir las demás versiones/capturas de Stitch del proyecto original.
